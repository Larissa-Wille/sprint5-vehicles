# Análise de Anúncios de Veículos

## Descrição do projeto

Este projeto foi desenvolvido como parte do Sprint 5 do programa de Análise de Dados da TripleTen.

O objetivo é criar um aplicativo web interativo para explorar dados de anúncios de veículos usados nos Estados Unidos.

## Funcionalidades

- Visualização da distribuição dos preços dos veículos por meio de um histograma.
- Análise da relação entre quilometragem e preço por meio de um gráfico de dispersão.
- Interação com os gráficos utilizando caixas de seleção.
